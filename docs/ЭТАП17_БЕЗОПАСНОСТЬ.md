# Этап 17 — Безопасность и защита данных

Ветка: `backup` (версия конфигурации 1.0.8).

## Что сделано

### PIN и биометрия
- Константы: `ИспользоватьПИН`, `ХешПИН` (SHA-256), `ИспользоватьБиометрию`
- Форма `ФормаРазблокировки` — ввод PIN / биометрия при старте и после пробуждения приложения
- Форма `ФормаБезопасности` — включение/отключение PIN, биометрии, скрытия сумм
- Старт: `ManagedApplicationModule` открывает разблокировку, если PIN включён
- `ПриПробужденииКлиентскогоПриложения` на начальном экране снова блокирует интерфейс

Биометрия: `ДополнительнаяПроверкаПользователя` (`ТолькоБиометрическая`), только на мобильном клиенте при поддержке устройством.

### Скрытие сумм
- Константа `СкрыватьСуммы`
- Маскирование в `ОбщийМодульСервер_КурсыВалют.ПредставлениеСуммыВВалютеУчета` → `••••` (главная, счета, операции, отчёты)
- Кнопка Hide/Show на карточке остатка главной (`app:toggle-amounts`)
- Переключатель в настройках безопасности

### Google-токены
- Хранение в `GoogleТокеныХранилище` (`ХранилищеЗначения` + сжатие), не в открытых строковых константах
- Миграция из `GoogleAccessToken` / `GoogleRefreshToken` при первом обращении
- Зеркало в `БезопасноеХранилище` ОС (если доступно на мобильном клиенте)
- Пароль Google по-прежнему не хранится
- Локальный бэкап сохраняется через диалог пользователя (`НачатьПолучениеФайлаССервера`)

### Подтверждение удаления
- Счета / категории / контакты / валюта — текст с числом использований
- Списки документов — `ПередУдалением` + `ПоказатьВопрос`, пометка удаления (архив)

## Модули
- `ОбщийМодульСервер_Безопасность`
- `ОбщийМодульКлиент_Безопасность`

## Проверка на устройстве
1. Настройки → Безопасность → включить PIN → свернуть приложение → убедиться в запросе PIN
2. Включить биометрию на поддерживаемом телефоне
3. Hide/Show сумм на главной и в отчётах
4. Удаление используемого счёта — предупреждение с количеством операций
5. Удаление документа из списка — подтверждение
