# Обмен расходами с Excel (CSV)

## Как сохранить из Excel

**Файл → Сохранить как → CSV UTF-8 (разделитель — запятая) (*.csv)**

Точка с запятой не нужна — загрузка понимает `,` (и `;` тоже).

| Колонка     | Пример                         |
|-------------|--------------------------------|
| Дата        | `01.01.2026`                   |
| ВидПлатежа  | `Обед`, `Разное (такси)`       |
| Сумма       | `280000.00` или `"280 000,00"` |

Пример:

```text
Дата,ВидПлатежа,Сумма
01.01.2026,Аренда квартиры,280000.00
02.01.2026,"Разное (такси)",2240.00
```

## Выгрузка из приложения

Тоже CSV с разделителем `,`, сумма с точкой (`1234.56`) — удобно открывать и снова сохранять в Excel.

**Настройки → Обмен расходами (Excel)**
