# Системная клавиатура vs Wallet

**Настройки → Константы → «Использовать системную клавиатуру устройства»**

| Значение | Поведение |
|----------|-----------|
| **Выкл.** (по умолчанию) | Цифровая и текстовая клавиатуры Wallet |
| **Вкл.** | Системная клавиатура устройства (`ПоказатьВводЧисла` / `ПоказатьВводСтроки`) |

Действует на ввод сумм, текста и телефона через `ОбщийМодульКлиент`.  
PIN, биометрия и выбор счёта/категории не затрагиваются.

Константа: `ИспользоватьСистемнуюКлавиатуру`.
