# Сборка мобильного приложения Wallet

Тестирование резервного копирования и Google Sign-In нужно выполнять в **мобильном приложении** (APK), а не в мобильном клиенте к серверной базе.

## Зачем именно МП

| Возможность | Мобильный клиент | Мобильное приложение |
|-------------|------------------|----------------------|
| Учёт, формы, HTML-UI | да | да |
| Системный выбор файла | ограничено | да (`PersonalComputerFileExchange`, `AllFilesAccess`) |
| OSBackup | декларация есть | работает в APK |
| Google «G» → выбор аккаунта Android | нет | да, через внешнюю компоненту |

## Что уже включено в конфигурации

В `Configuration.mdo` → `usedMobileApplicationFunctionalities`:

- базовая функциональность
- `OSBackup`
- `LocalNetwork` (HTTPS: курсы, Google API)
- `PersonalComputerFileExchange`
- `AllFilesAccess`

Версия конфигурации: **1.0.8**.

## Шаги сборки (когда будете готовы)

1. Выгрузить / опубликовать конфигурацию в **Сборщик мобильных приложений**.
2. Создать приложение Android, указать package name (например `kz.wallet.uchet`).
3. Собрать debug/release APK и установить на телефон.
4. Проверить: **Настройки → Резервное копирование**.
5. После появления компоненты `WalletGoogleSignIn` — пересобрать APK с макетом внешней компоненты.

Подробный контракт компоненты: [`GOOGLE_SIGNIN_КОМПОНЕНТА.md`](GOOGLE_SIGNIN_КОМПОНЕНТА.md).

## Чек-лист прогона на телефоне (позже)

- [ ] Локальная резервная копия создаётся и сохраняется в выбранную папку
- [ ] Восстановление из локального файла с предупреждением
- [ ] Кнопка «Войти через Google» открывает системный выбор аккаунта
- [ ] Email отображается в статусе, токены без пароля
- [ ] Копия в Google Drive / восстановление из Drive
- [ ] Отключение аккаунта очищает сессию
