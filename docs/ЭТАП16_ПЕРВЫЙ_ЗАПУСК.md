## Сценарий первого запуска

1. `ФормаПервогоЗапуска` открывается, если `ПервыйЗапуск = Ложь`.
2. **Приветствие** → Начать / Пропустить.
3. **Валюта** → список KZT/RUB/USD/EUR.
4. **Счёт** → тип, имя, остаток → Готово.
5. Флаг начальной настройки устанавливается; предопределённые счета инициализируются.

Пропуск: валюта по региону + тема «Системная», без документа остатка.

## Настройки

- Валюта учёта → `ФормаКонстант`
- Тема → цикл Светлая → Тёмная → Системная
- Резервное копирование
- Версия конфигурации внизу экрана

## Технические детали

- `ОбщаяФорма.ФормаПервогоЗапуска`
- `ОбщийМодульСервер_СистемныеНастройки` — `ВалютаПоУмолчаниюПоРегиону`, `ЗавершитьПервыйЗапуск`, `ПропуститьПервыйЗапуск`, тема
- Константа `ТемаПриложения`
- Версия конфигурации: **1.0.9**
