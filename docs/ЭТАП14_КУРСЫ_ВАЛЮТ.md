# Этап 14. Автообновление курсов валют

Цель: одна настройка `АвтообновлениеКурсовВалют` управляет и загрузкой курсов, и режимом их использования в документах.

Источник в Notion: [Этап 14 — Регламентное обновление курсов валют](https://app.notion.com/p/0d421f9095e64535ad29bbd91668f2fa).

## Что сделано

| Пункт | Статус |
|-------|--------|
| Константа `АвтообновлениеКурсовВалют` | готово |
| Включено: курс на дату операции + загрузка при старте | готово |
| Выключено: последний известный курс, без автозагрузки | готово |
| Загрузка RUB / USD / EUR относительно `ВалютаУчета` | готово |
| Источник: `open.er-api.com` (HTTPS) | готово |
| Не перезаписывать курс пустым / ошибочным значением | готово |
| Команда «Обновить курсы сейчас» на форме констант | готово |
| Документы используют курсы по выбранному режиму | готово |

## Как пользоваться

1. **Настройки → Константы**
2. Включить «Автообновление курсов при старте приложения» — нужны точные курсы на дату.
3. Выключить — в операциях берётся последний известный курс; при старте курсы не качаются.
4. Нажать **«Обновить курсы сейчас»** — сообщение: успешно / нет изменений / ошибка.

## Технические детали

- Модуль: `ОбщийМодульСервер_КурсыВалют`
- API: `GET https://open.er-api.com/v6/latest/{КодВалютыУчёта}`
- Курс в регистре: единиц валюты учёта за 1 единицу валюты операции (`1 / rate_api`)
- Константа `ИспользоватьПоследнийИзвестныйКурс` удалена — поведение завязано на автообновление
- В `usedMobileApplicationFunctionalities` включён `LocalNetwork` для HTTPS

## Проверка

- [ ] Ручное обновление при валюте учёта KZT заполняет курсы RUB/USD/EUR на сегодня
- [ ] При включённом автообновлении документ требует курс на дату операции
- [ ] При выключенном — берётся последний известный курс
- [ ] При старте с включённой настройкой и без курсов на сегодня выполняется загрузка
